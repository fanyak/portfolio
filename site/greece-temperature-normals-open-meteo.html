Recreating a Data-Driven Temperature Normal for Greece

Fani Akritidou • 8 min read • Data Analysis

Building a national temperature anomaly chart in Python, with public sector and Open-Meteo data, using cross-validated smoothing.

Note: This project was inspired by Dominic Royé's A data-driven normal for the Spain temperature chart. That article creates an anomaly chart for Spain using R. It is a great article and I urge you to read it! Here I recreate the methodology in Python, with data from greek meteorological stations.

Setting the Goal

Comparisons of daily temperatures provide little information about how unusual temperatures are between years. What is actually informative is a smooth daily climatological reference, which allows us to compare data without the day-to-day noise. Creating a climatological normal against which we can compare the daily mean temperature is the theme of Dominic Royé's article.

The challenge then is to figure out how to smooth a daily climatological reference without either following the noise or flattening real features. This is a model-selection problem where we need to choose between families of smoothers. Our preferred families are two: loess and harmonic regression. Both of these smoothers can be tuned and (re-)evaluated in a cross-validation process.

Tools and Data

This project tries to port the original methodology from R to Python. I used the following packages:

  • pandas and NumPy for data manipulation
  • Matplotlib and Seaborn for visualization
  • statsmodels for LOWESS/LOESS smoothing and regression
  • scikit-learn for K-fold cross-validation
